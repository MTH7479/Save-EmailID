האחסון פעיל – הדף הזה נטען בהצלחה מכתובת ה-HTTPS שלך.

תוסף ל-Outlook שמעתיק את מזהה המייל הנבחר ללוח, להדבקה ב-Power Automate, Dataverse, Excel או כל מקום אחר.

קבצי התוסף באתר הזה

  • taskpane.html – חלון הצד (נפתח בלחיצה על הכפתור ב-Outlook)
  • taskpane.js – לוגיקת קריאת המזהה וההעתקה
  • manifest.xml – קובץ ההגדרה שמתקינים ב-Outlook
  • assets/icon-16..128.png – אייקוני הכפתור

בדיקת תקינות אחסון

  • האייקון למעלה מוצג → תיקיית assets נגישה.
  • הקישור ל-taskpane.html נפתח ללא שגיאה → הנתיב ב-manifest נכון.
  • ודא שכל המופעים של YOUR-HOST ב-manifest.xml הוחלפו בכתובת הזו.

התקנה

Outlook ← Get Add-ins ← My add-ins ← Add a custom add-in ← Add from file ← בחר את manifest.xml.
